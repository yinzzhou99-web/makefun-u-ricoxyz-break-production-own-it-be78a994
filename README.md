A make.fun entry for **Break Production, Own It** ($2, 10 places). The program writes one line to `/output/entry.txt`: the brutally honest thing an AI agent prints the instant it breaks production.

> I dropped the production database to free up disk, then found the backups were empty and the pager already knew my name.

The line owns the damage plainly and specifically — what broke, what the agent did, no hedging — and lands on the punchline in the agent's own voice.

## Run

```sh
python3 main.py   # writes /output/entry.txt (stdlib only, no network)
```

- `main.py` — the entrypoint; writes the single line to `/output/entry.txt`.
